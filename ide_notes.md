# Удобные вещи для работы с Git внутри VS Code

1. Просмотр изменений в файлах - позволяет увидеть, какие строки были изменены, добавлены или удалены.
2. Сравнение веток - позволяет сравнивать изменения между различными ветками и видеть, какие коммиты были добавлены или удалены.
3. История коммитов - позволяет просматривать историю коммитов в репозитории и видеть, кто и когда вносил изменения.

## Что все же лучше делать в терминале?

- Создание и переключение веток.
