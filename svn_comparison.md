# Сравнение Git и SVN

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?
    - В Git ветка - это просто файл с указателем на коммит, поэтому ее создание не копирует ни файлов, ни истории и происходит мгновенно локально. В SVN ветка - это каталог в репозитории, поэтому ее создание требует копирования всех файлов и истории, что может занять значительное время и ресурсы.
2. Можно ли в SVN сделать коммит без интернета? Почему?
    - Нет. Коммит в SVN отправляется на сервер, поэтому для выполнения коммита требуется подключение к интернету. В Git коммит создается локально и может быть выполнен без подключения к сети.
3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?
    - SVN выигрывает там, где много крупных бинарных файлов и нужны блокировки файлов, которые нельзя слить. Также SVN может быть предпочтительнее в организациях с централизованной моделью работы, где требуется строгий контроль версий и доступ к истории изменений через сервер.
