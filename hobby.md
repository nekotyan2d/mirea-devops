# Мой пет-проект

Идея: телеграм-бот, который постить в канал сгенерированные нейросетью тексты новостей на основе последних новостей из RSS-ленты. Бот будет использовать API нейросети для генерации текста и публиковать его в канал с определенной периодичностью.
Стек: Node.js
Цель: научиться работать с API нейросетей и автоматизировать процессы.
